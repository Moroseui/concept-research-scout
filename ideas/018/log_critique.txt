Critique written to `ideas/018/critique.md`. **Decision: REJECT**, with a well-evidenced successor recommended as a new candidate.

**The fatal objection:** both assets the design requires fail direct inspection. GRASP released training code only — no weights, no inference entry point — and its data is "by request," which the charter forbids relying on. And the longitudinal tumor-stable arm has no cohort to run on anywhere: LUMIERE (the only public serial GBM MRI dataset) is skull-stripped for anonymization, so the temporalis is deleted by construction; UPenn-GBM's 60 follow-up scans are all second resections for *progression*, anti-selected against the tumor-stable pairs the design needs; BraTS-family data is skull-stripped by definition. This is idea-014's failure mode (model asset not reproducible) realized rather than risked — a resemblance the card's `dies_like_prior` field missed.

I also flagged a confound the card omitted: **age**. Age dominates GBM survival prediction, temporalis area declines with age, so "frailty" in the deliverable sentence is interpretive gloss of exactly the kind idea 015 was made to drop. The defensible sentence is "the model is using temporalis muscle bulk."

**The constructive part is unusually strong.** The adversarial search verified that: the temporalis segmentation tool has public code on GitLab and was validated on public TCIA collections (TCGA-GBM, IVY-GAP, REMBRANDT — proving temporalis survives in standard public GBM imaging); and UPenn-GBM (630 patients, CC BY 4.0) releases **unstripped, defaced structural scans plus overall survival** — the only modern open cohort where the muscle, the labels, and the measurement tool coexist. The successor: train a whole-head survival model on UPenn-GBM, gate on beating an age+sex baseline, then temporalis-only substitution with shams. Its keystone (does the defacing mask spare the temporalis?) is checkable in an afternoon by downloading a few cases. Per the claim-identity rule it should re-enter scouting as a new candidate with `parent_ids: ["idea-018"]`.
