**The five candidates, ranked by priority:**

1. **c02 (Mode B, 4.15) — "CT-CLIP separates atelectasis from consolidation using lobar volume loss."** The strongest card: the primary readout is the within-scan contrast between the two heads (scanner, protocol, patient all differenced out by construction), against lobar volumes from TotalSegmentator, conditioned on measured opacity burden. Keystone INSPECTED_TRUE — the repo's own idea-004 probe log contains the official 18-head list with Atelectasis and Consolidation as separate heads, and the inference pipeline already exists locally. The honest residual: lobe segmentation fails exactly where collapse is severe, so the primary analysis is restricted to mild-moderate volume loss with a QC gate.

2. **c04 (Mode C, 4.05) — "CT-CLIP is using IVC distension and roundness as a central-venous-pressure gauge."** Longitudinal within-patient design on CT-RATE repeat sessions, with the idea-004 reconstruction pairs reused as a free annotation-less noise floor for both the model scores and the segmentation. Explicitly distinguished from idea-016's identifiability kill: non-contrast data removes the injection-protocol axis entirely. Keystone honestly NOT_INSPECTED (non-contrast IVC segmentation reliability is the load-bearing unknown).

3. **c05 (Mode C, 3.9) — "Merlin is using aortic tortuosity — a buckled, chronically over-pressurized column — to predict hypertension."** Keystone INSPECTED_TRUE: the Merlin paper names hypertension verbatim among its six 5-year targets and HuggingFace lists the five-year prediction weights (MIT). The buckling analogy survives the analogy-drop test because it dictates analyses (onset nonlinearity, radius-scaled undulation wavelength) a plain regression wouldn't run. The card states it dies like idea-009 if public cohorts lack age metadata, and makes that a Stage 0 kill gate.

4. **c01 (Mode A, 3.85) — "CXR-Age is using the cardiothoracic ratio and lung area."** Weights verified public (checkpoint path quoted from the README), CheXmask heart/lung masks verified open-access CC BY 4.0. The novelty scan surfaced important adjacent work — qCXR-bioage (DOI 10.1148/ryct.250327) builds its own explainable age from CXR quantifications but does not decode the existing CXR-Age checkpoint; that delta is recorded as the exact gap.

5. **c03 (Mode B, 3.5) — "Merlin is using splenic volume — congestive splenomegaly — in its chronic-liver-disease prediction."** Identification comes from natural wrong-cause cases (non-hepatic splenomegaly). Scored lowest because its keystone (whether a usable cirrhosis output is actually exposed) is NOT_INSPECTED, capping feasibility at 3 per the rubric.
