Critique written to `ideas/044/critique.md`. **Decision: ADVANCE TO REVISION — no fatal objection**, but five required repairs, all compatible with keeping the question intact.

What the adversarial pass found:

- **No fatal flaw, and the novelty delta holds.** The "brain frailty" NCCT literature (old infarcts, atrophy, leukoaraiosis predicting stroke outcome — IST-3 and successors) is rich but purely associational; I found no prior intervention-style test of whether a model *uses* chronic cavities. However, some of that literature finds old infarcts the *weakest* frailty marker, which lowers the prior and raises the stakes on sensitivity gates.
- **The deliverable overclaims** — "brain-reserve signal" is an interpretation the design can't identify (the card admits this itself). Same defect class as idea 023, same remedy: reduce the claim language in place. The plain pitch carries the same overclaim ("treats the patient as more vulnerable"), a named pitch defect.
- **The edit touches only the NCCT channel** while the cavity necessarily still shows in the CBV/CBF maps and CTA — so a positive scopes to NCCT-channel use, a negative is biased toward null, and the edited input is cross-modally inconsistent (the idea-006 OOD lesson). The card's CSF sham accidentally controls part of this; the revision should claim that control explicitly.
- **A genuine design bug**: the "mirrored homologous" donor tissue for a *contralateral* cavity lies in the *affected* hemisphere, possibly inside the acute ischemic territory — the fill could import ischemic texture. Cheap fix: donor exclusion rule plus fallback to the second fill method.
- **No frozen model is named**, and the verified state of the art is weak — I confirmed the ISLES'24 winner scored Dice 0.285 ± 0.213 (arXiv [2408.10966](https://arxiv.org/abs/2408.10966); winner method arXiv [2505.18424](https://arxiv.org/abs/2505.18424), no release statement found). The revision must name the model path, define the currently-undefined performance gate numerically, and add an NCCT-channel ablation gate — if the model ignores NCCT, every null is vacuous.
- **The 15-of-30 (50%) prevalence gate is uncited and likely miscalibrated** for cavitated ≥1 mL contralateral lesions; census all 149 public cases and gate on a power-derived editable-case count instead.

The constructive close finds the nearest defensible question is this same candidate with reduced claim language — worth doing conditionally, because the census-first design answers the killing questions in about two days before any expensive commitment. The stage driver will pick up the file for commit.
