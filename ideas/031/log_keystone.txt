**Verdict: KILL (DATA_ACCESS).** The keystone screen for idea 031 is written to `ideas/031/keystone_screen.md`. The keystone is demonstrably false on its load-bearing clause: the ISLES'24 release contains no distal-vessel pseudolabels, so the proposed collateral-reach measure cannot be computed from released files.

What I verified, against three primary sources:

- **Occlusion masks: real.** The official Zenodo release (record 16813698, 149 cases, CC BY-NC-SA 4.0) lists per-case `lvo-msk.nii.gz` in NCCT-registered derivative space; the dataset paper (arXiv:2408.11142v2, the arXiv version of the cited Radiology: AI paper) says they were drawn manually by a neuroradiology resident and reviewed by an attending, marking "the final segment of the vessel before the occlusion."
- **Vessel pseudolabels: real, but proximal only.** The release schema defines `cow-msk.nii.gz` as "multi-labeled Circle of Willis anatomy"; the paper's complete label legend lists only ACA, AcomA, ICA, MCA, PCA, and basilar, calls the masks a "silver ground-truth… coarse reference segmentation not traced by experts," and a targeted verbatim sweep found no mention anywhere of M2/M3/M4, pial, or distal-branch segmentation.
- **The decisive quote** comes from the TopCoW annotation protocol (arXiv:2312.17670v3, §2.7), which the Zenodo record requires citing for these masks: "we typically only labelled until the first major bifurcation occurs, and we only labelled the main vessel instead of any minor branches."

The card's X_measurement — distal vessel-length density in territories downstream of the occlusion — therefore has essentially zero labeled vessel to measure: the pseudolabels stop where the measure begins. Credit where due: the card's own residual-assumption line correctly predicted that distal coverage was the real keystone, so this is the screen working as intended — the idea dies at screen prices, not after critique, debate, and a Stage 0 file audit.

One caveat recorded honestly: I did not download the 99 GB archive, so per-case file completeness was verified at the release-schema level only — moot given the distal-coverage kill. The screen also records a salvage path without endorsing it: running fresh distal cerebrovascular segmentation on the released CTA would be a successor candidate under the claim-identity rule (different X_measurement), not a repair of this card.
