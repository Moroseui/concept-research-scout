## Critique complete: ADVANCE TO REVISION

`ideas/021/critique.md` is written. The idea survives, but with one objection that is fatal to the design **as written** and repairable without changing the question.

**The decisive objection.** The card's entire identifiability argument is the sentence "no pathway from edit to readout exists except through a learned cross-hemispheric reference." That's false under the stand-in model's own default preprocessing: nnU-Net's documentation (primary source, verified today) applies **per-image z-score to all non-CT channels**. Scaling contralateral CBF changes the whole-image mean and standard deviation, so every affected-side voxel's post-normalization value changes deterministically before the network runs — a positive result would be manufactured by preprocessing arithmetic, with exactly the signature the hypothesis predicts. The same default also deletes the null arm: after per-image z-score the model cannot see absolute perfusion values, so "null ⇒ model reads absolute values" is unavailable by construction. This is the charter's wrong-keystone pattern in a fourth costume — co-registration (the stated keystone) was genuinely inspected true, but the load-bearing fact for identifiability is the frozen pipeline's normalization scheme, which was never inspected. The repair is cheap and within the study's control since the model is self-trained: pin normalization statistics to the unedited image (or use fixed cohort-level constants), and restate the dichotomy as *mirror-specific reference vs whole-image standardization* — which is still the clinically meaningful distinction, since Campbell's rCBF convention is mirror-specific precisely because the healthy hemisphere is uncontaminated by the lesion.

**Other findings that survived verification:**
- **Prior work reframing** — no intervention-grade audit of a trained stroke model's reference frame exists (novelty holds narrowly), but the field extensively *hand-engineers* the mirror into stroke networks (symmetric modality augmentation gained 9–13 Dice points, [arXiv 1907.08196](https://arxiv.org/pdf/1907.08196)); the delta must be restated against that literature, and it is indirect evidence the expected answer is "no."
- **Power unexamined** — the ISLES'24 winner's hidden-test Dice is 0.285 ± 0.213 ([arXiv 2408.10966](https://arxiv.org/abs/2408.10966)); the winner released no code or checkpoint (their paper is titled ["How We Won the ISLES'24 Challenge by Preprocessing"](https://arxiv.org/html/2505.18424v1) and doesn't disclose normalization). The card needs a minimum-detectable-effect analysis before calling 40 cases decisive, and `prior_legwork`/`feasibility` drop to 3.
- **Edit realism** — "mimics cardiac-output variation" is wrong (cardiac output is global); hemisphere-restricted scaling instead mimics unilateral carotid disease, adding an unlisted alternative: the model may reinterpret laterality rather than rescale a reference. Diagnosable via an up/down-scaling asymmetry contrast, which must be preregistered.

**Constructive close:** the nearest defensible question keeps the same deliverable sentence — under pinned normalization, three arms (global, contralateral-only, partial-area scaling) separate "no reference / whole-image reference / mirror reference" with the machinery the card already has. It's worth doing: both answers change how ISLES'24-class models should be preprocessed and trusted.
