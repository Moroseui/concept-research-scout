Wrote `ideas/014/critique.md`. Verdict: **PAUSE**.

The decisive finding came from inspecting the keystone rather than an adjacent fact. The whole design "freezes the Pierson pain model, probes its embeddings, and erases a texture direction" — but `github.com/epierson9/pain-disparities` ships **training code only, no released weights**, on a Python 3.5.2 stack that needs raw registration-gated OAI DICOM and reportedly terabyte-scale preprocessing. So the frozen representation everything depends on does not exist as a downloadable artifact; it would have to be reproduced and re-validated first. The card had this as an unverified assumption (`keystone_status: NOT_INSPECTED`, "a runnable checkpoint is currently available"); it is now verified false-as-stated. This is the loop's recurring wrong-keystone shape — the easy fact ("both use OAI") was checked, the load-bearing one ("there is a runnable model to erase from") was assumed.

Two further problems the revision must fix even if the model is reproduced:
- **Identifiability of the *directional* claim.** Erasing one texture direction versus KL/JSN controls supports at most "the model uses subchondral bone texture/density" — entangled with the disease severity the model is expected to read — not the "directional load-path architecture" in the deliverable sentence. By the charter's own test, dropping the mechanobiology analogy changes nothing about the code as written, so the analogy is currently decoration. It becomes load-bearing only if the primary readout is horizontal-vs-vertical (vs isotropic-density) specificity.
- **The measurement X is acquisition-sensitive.** Radiographic fractal texture moves with detector, pixel spacing, and exposure across OAI's multi-site acquisition — a place a site/race proxy could hide. The card's strongest, underused move is the within-film left-vs-right knee contrast (both knees, one exposure), which is nearly acquisition-immune and is the "compare the model to itself" survivor pattern — but only if the network scores acquisition-matched single-knee crops, which needs checking in `image_processing.py`.

The critique also flags a genuinely worthwhile, unblocked spin-off: an association-only, no-model, no-retrain OAI study asking whether directional medial-tibial subchondral texture explains KLG-discordant pain as a within-person asymmetry. It partly drops the "what is the model using" framing but serves as a cheap decisive gate — a null there kills the flagship before anyone reproduces a 2021 model.
