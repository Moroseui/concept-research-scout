The critique is written to `ideas/023/critique.md`. Decision: **ADVANCE TO REVISION — no fatal objection**, but three mandatory repairs before a feasibility memo.

What the review found, briefly:

- **Principal objection (new, not in the card):** the ISLES'24 maps were generated by icobrain cva using conventional tracer-kinetics deconvolution (verified in arXiv:2408.10966), where MTT is typically *derived* as CBV/CBF. If that identity holds by construction, the "Little's law residual" is a tautology of the vendor pipeline, and — more damagingly — the confirmatory co-edit moves CBV and MTT in lockstep at fixed CBF, so a positive result can never attribute the response to blood volume rather than transit time. Repairable with a prohibited-conclusion line: the claim becomes "the model uses the compensation *state*," which the deliverable sentence's own wording already supports, so the claim-identity rule is not triggered.
- **The two-sided discriminator doesn't discriminate as written:** for the listed compensated↔collapsed toggles, the reserve-construct reader and a generic "low CBV = bad" channel reader predict the *same sign*. Separating them requires the above-mirror saturation arm, which the card mentions in passing but never puts in the experiment. Identifiability is a 3, not a 4, until that arm is explicit.
- **A missing Stage 0 gate that is also free science:** nobody checked whether the *ground truth* carries the interaction — at matched CBF decrement, do final-infarct rates differ by CBV state in the 149 released cases? CPU-only, uses only existing public data, re-litigates Wintermark-vs-Campbell on a modern treated cohort, and if it fails the toggle null is preordained. This is the low-hanging fruit: worth running before any GPU time.
- **Scope honesty:** the probe target is a self-trained nnU-Net (no challenge checkpoint confirmed released; the winning-solution paper arXiv:2505.18424 releases none), so "what benchmark models internalized" must be trimmed, and the cycle-shared model must be prespecified to take the maps as input channels or the edits have no port of entry.
- **Kill-attempts that failed:** prior-work overlap (nearest neighbors perturb clinical/treatment variables, not map-encoded physiological state), circularity, leakage, annotation provenance, confounding, data access, compute — all survived, and are recorded so they aren't re-run. Minor flags: Zenodo version churn (pin the record version; schema stable across the two versions inspected) and the monolithic ~99 GB archive.

I left the file uncommitted, matching how this stage's other artifacts arrived.
