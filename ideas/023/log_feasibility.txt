The findings that matter:

**The operator's kill condition is not triggered.** The mandated prior-art section found workable precedent at every layer the design needs: counterfactual input probing in the exact task family (Robben et al. 2020, PMID 31683091, treatment-metadata counterfactuals on CTP final-infarct models; Amador et al. 2024, clinical-variable counterfactual scenarios), accepted counterfactual image editing in neuroimaging (Pawlowski NeurIPS 2020; Sanchez & Tsaftaris CLeaR 2022), and routine arithmetic manipulation of these exact map types in clinical-methods work (Kellner AJNR 2024 mirror normalization; the DEFUSE-3/DAWN rCBF<30%-of-contralateral standard). What has no precedent is the identity-preserving *joint* edit itself — but that is a realism constraint added on top of precedented operations, harsher versions of which (occlusion/zeroing) are standard. The memo gives the required stay-in-distribution strategy with numbers: doses f ∈ {0.70–1.30} co-scaling CBV and MTT, clamped to native per-stratum [q05, q95], a 99% highest-density-region gate, ≤10% clamping per cell, and the full control battery.

**Two material updates to the card, both favorable.** First, the assumption that no challenge weights exist is now false: the challenge paper links code for all three top teams, and the #2 submission (AMC-Axolotls, Dice 0.263) verifiably takes rCBF/rCBV/MTT/Tmax as input channels with weights on Google Drive — a real benchmark model with a port of entry for the edits (multimodal, so secondary per the card; link liveness unverified). The winner's repo also distributes weights, but its exact input channels are stated nowhere and must be read from its released plans files. Second, the clinical-data description file is separately downloadable (~12 MB), so whether mTICI/treatment variables exist — still unverified — costs minutes to resolve, not the 99 GB download.

**The honest weak points, named rather than papered over:** the archive is monolithic (no derivative-only retrieval; ~99 GB download unavoidable), the Zenodo record has active version churn (latest is now v6, record 17652035, 2025-11-20 — hash pinning is mandatory) plus a 149-vs-150 case-count discrepancy, and the single biggest risk is statistical power: the patient-clustered outcome census on ~100 census patients may fail its precision gate. That is a cheap, early, named death that still yields a citable observation. I also imported one lesson from the idea-021 external brief as a new Stage 0 requirement: inspect each probed model's normalization scheme and add a normalization-statistics-held-fixed edit variant, since per-instance z-scoring can couple regional edits to global statistics.
