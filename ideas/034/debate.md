# Debate transcript

## Round 1 — CRITIC

**Position:** The proposed design cannot answer the original model-use question because CTP slab membership is inseparable from the presence or absence of local perfusion evidence.

**Argument:** The deliverable contrasts a model using the sensor boundary with a model using ischemic evidence, but stage 2 compares locations where all CTP values are available with locations where they are blank or absent. Atlas-location matching and conditioning on NCCT, CTA, or follow-up lesion volume do not hold perfusion evidence constant, so any boundary-locked prediction change is equally explained by ordinary reliance on CBF, CBV, MTT, or Tmax. The organizer's statement that ISLES'24 is multimodal strengthens the benchmark-audit motivation but does not identify this mechanism: NCCT and CTA coverage cannot substitute for the missing counterfactual CTP values. A crop intervention has the same defect and adds distribution shift. Removing stage 2 and retaining the released-cohort overflow census would be scientifically worthwhile, but it would answer the critique's separate question about CTP-support-constrained evaluation, not the card's original question about whether a final-infarct model uses the support boundary; under the claim-identity rule that must be a successor candidate.

**What would change my mind:** Show an obtainable, validated in-distribution intervention on a frozen held-out model that moves or removes the support-boundary cue while preserving voxelwise perfusion evidence, NCCT/CTA evidence, anatomy, and preprocessing inputs in the tested region, plus a prediction contrast whose alternatives differ specifically in boundary use; otherwise only the model-free audit is identifiable.

**Status:** OPEN

## Round 1 — PROPOSER

**Responding to:** Slab membership and perfusion-evidence availability are the same variable in the stage-2 design as written: out-of-slab locations differ from in-slab locations in exactly the evidence whose absence defines them, so no cross-patient matching on NCCT, CTA, atlas position, or lesion volume can separate "the model uses the boundary" from "the model uses perfusion values that end at the boundary." A naive crop shares the defect and adds distribution shift. Only the model-free census is identifiable, and keeping only the census would change the claim's identity.

**Response:** AMEND

**Argument:** The objection is correct against stage 2 as carded, and that part is conceded outright: the cross-patient in-slab/out-of-slab contrast cannot support the deliverable sentence and is demoted to descriptive/exploratory. But the critic's own mind-changer condition — move the boundary cue while preserving all evidence *in the tested region*, with a contrast whose alternatives differ specifically in boundary use — is satisfiable within the original one-sentence question, and the amendment adopts exactly that.

Amended stage 2, confirmatory design (conditional, as before, on stage 1 passing and a frozen held-out checkpoint existing):

1. **Boundary-moving arm (truncation at preserved evidence).** Take released wide-slab cases and truncate the perfusion support to a narrower slab, using the release's own empty-region fill convention (the forum describes real out-of-support regions as "completely empty"; the exact zeros/NaN convention is read off downloaded narrow-slab cases before any edit, and the fill copies it bit-for-bit). Fake edge z-positions are sampled from the empirical slab-edge distribution measured by stage 1's census, so the edited support geometry lies inside the geometry distribution the model was trained on — narrow slabs are not an out-of-distribution invention here, they are a documented property of this release. That answers the crop's distribution-shift objection with a checkable realism criterion (edited support geometries must be within the observed census distribution), not an assumption. The tested voxels are retained voxels whose network inputs are unchanged — verified bit-for-bit, with any per-instance normalization constants frozen from the unedited case, the same pin the operator already endorsed for idea 021 — but whose receptive field spans the moved boundary. At those voxels every piece of evidence (perfusion, NCCT, CTA, anatomy, preprocessing) is held constant by construction; only the boundary position changed. Any prediction change there is caused by the edit.

2. **Boundary-fixed content arm (the discriminator).** The critic's crop objection is that truncation "removes true perfusion evidence while moving the boundary." True — in the removed region. The residual ambiguity at the tested voxels is therefore "the model uses boundary position" versus "the model uses the removed distal content as context." Arm 2 separates them: same distal region, support boundary unchanged, distal *content* replaced with in-distribution donor values (registered healthy slab content from another case, or the unedited case's own contralateral values), evidence at tested voxels again bit-identical. If tested-voxel predictions track boundary position (arm 1 responds) while remaining insensitive to distal content at fixed boundary (arm 2 quiet), the support boundary itself is a spatial determinant of predicted extent at fixed local ischemic evidence — the deliverable sentence, rung 1, scoped to the tested checkpoint. If both arms respond comparably, the answer is "distal context use, not boundary use," which is a decisive negative for the original claim, not an ambiguous one.

**Identity check:** the one-sentence question is whether the model uses the support boundary as a determinant of predicted lesion extent. The amendment replaces the estimator (observational cross-patient contrast → paired within-case intervention with a discriminating arm), not the question. Stage 1, the census gate, is untouched. This is not the census-only successor the critic correctly said would be a different claim.

**What is lost, stated plainly:**

- The confirmatory claim narrows from "final-infarct models" to "this frozen held-out checkpoint," and stage 2's carded cost is wrong: no shared audit model is verified to exist, so feasibility must price obtaining or training one (order GPU-days for a baseline on 149 cases, not the carded <5 GPU-hours). The critique's cost objection is accepted.
- Arm 2 requires a concrete stay-in-distribution edit strategy with numbers; per the idea-023 feasibility condition, absence of workable precedent for such edits is a legitimate kill. If arm 2 proves unbuildable, arm 1 alone supports only the weaker sentence "predicted extent at fixed local evidence is sensitive to slab extent" — boundary-or-distal-context, undiscriminated — and the full deliverable is not claimable from arm 1 alone. I state that now so it cannot be blurred later.
- Behavior beyond the sensor edge (truncate-versus-extrapolate convention) becomes descriptive only: the truncated run's out-of-fake-edge predictions can be compared against the unedited run's known predictions there, but per the concession above no use attribution attaches to out-of-support behavior.
- Stage-1 collateral amendments from the critique are accepted in the same pass: the oracle is renamed to "CTP-support-confined oracle Dice" with its constrained definition stated, all leaderboard-movement language is deleted absent actual team predictions, and every census claim is scoped to the released training cohort under the preregistered support definitions.

This is a real weakening — the surviving idea is a gated, checkpoint-conditional, two-arm intervention study whose discriminating arm carries a named feasibility risk — but it answers the original question rather than abandoning it, and it meets the critic's stated bar: boundary cue moved, evidence in the tested region preserved and bit-verified, alternatives separated by a designed contrast rather than by matching.

**Status:** OPEN

## Round 2 — CRITIC

**Position:** The two amended arms still do not isolate use of a support boundary, because in these inputs the boundary is constituted by replacing distal perfusion content with the empty-region fill, and the proposed content control does not reproduce that change while holding the boundary fixed.

**Argument:** The amendment preserves the original question, so it passes the identity check, and testing only retained voxels with frozen normalization adequately answers the earlier local-evidence objection. The remaining problem is the discriminator. Unless the frozen model receives an explicit support-mask or boundary channel, there is no independently manipulable “boundary cue”: the model can detect the edge only from the transition between ordinary perfusion-map values and the release's empty fill. Arm 1 therefore changes both that transition and all distal activations generated by replacing the removed slab with fill. Arm 2 replaces the distal slab with registered healthy or contralateral values while leaving it nonempty; this is neither the same distal-content perturbation nor the same activation regime as empty fill. A quiet arm 2 cannot rule out use of distal content that responds specifically to its deletion, to fill-value runs, or to the resulting feature-map discontinuity. Conversely, calling sensitivity to that discontinuity “boundary use” makes the proposed alternative inseparable by definition: the support boundary has no observable existence apart from the content transition. Sampling an edited slab width from the empirical distribution establishes only marginal geometric plausibility, not that truncating a particular wide-slab case yields an in-distribution joint image; scanner, protocol, slab placement, anatomy, and perfusion content may covary. Thus an arm-1 response plus an arm-2 null identifies sensitivity to the truncation operation, not use of boundary position rather than removed distal context. This is the same load-bearing identifiability failure in a paired design, not a feasibility detail about choosing better donors.

**What would change my mind:** Show that the target checkpoint consumes an explicit support-mask/boundary channel and intervene on that channel while holding every perfusion-map voxel fixed, with preprocessing and joint-support realism validated; or provide a validated generative intervention that independently crosses boundary position and distal perfusion content, including an empty-fill-matched content control, and demonstrate on known-mechanism synthetic models that the resulting factorial contrast separates boundary-position use from deletion/fill/discontinuity sensitivity.

**Status:** OPEN

## Round 2 — PROPOSER

**Responding to:** In a model with no explicit support-mask channel, the "boundary cue" has no existence independent of the content-to-fill transition; arm 1 therefore moves the boundary only by deleting distal content into fill, arm 2's donor substitution reproduces neither the deletion nor the fill-activation regime, and marginal geometric plausibility of the fake edge does not make the truncated joint image in-distribution. So arm-1-responds-plus-arm-2-quiet identifies sensitivity to the truncation operation, not boundary use as distinct from removed-context use — and calling discontinuity sensitivity "boundary use" would make the alternative inseparable by definition.

**Response:** AMEND

**Argument:** One part of the objection is a logical point I contest; the rest is correct and is adopted wholesale, using the critic's own mind-changer as the specification.

**The contested part.** The critic's factorial — cross boundary position with distal perfusion content independently — contains a logically empty cell for a mask-free model. "Boundary at z_e with perfusion content preserved beyond z_e" is a contradiction in the input space: for a model whose only channels are the maps themselves, the boundary *is* the location where content gives way to fill. Likewise, "distal content use that responds specifically to its deletion but not to substitution among valid values" is not an alternative mechanism to boundary use — deletion into fill *is* relocation of the transition; those are two names for one causal variable. When two hypotheses are not separately realizable in any physically possible input, failure to separate them is not an identifiability failure of the design; it is the demand to distinguish indistinguishables. And the rung-1 deliverable does not need the internal taxonomy: whether the network reads the sensor's edge via fill runs, via a feature discontinuity, or via a mask channel, all are reading the sensor's edge; the sentence claims the *output* is determined by where the sensor stopped rather than where the ischemia stopped. The card must state this operational identity explicitly rather than leave it implicit — that change is part of this amendment.

**The correct part, conceded.** Three components of the objection are real and survive the logical point: (i) whether the frozen pipeline consumes an explicit support/valid mask (or crops to support) is an inspectable fact that changes the whole design, and it is currently uninspected; (ii) a *synthetic* truncation may elicit responses a *real* acquisition edge would not — the operation-artifact worry — and marginal geometry sampling does not answer it; (iii) generic sensitivity to fill runs or discontinuities *anywhere* is separable from edge-terminal-specific behavior, and the current arms do not separate them. The amendment addresses exactly these three:

1. **Gate A — pipeline inspection first.** Before any edit, inspect the frozen checkpoint's input specification and preprocessing. If it consumes an explicit support/valid-mask channel or a support-derived crop, the primary confirmatory arm is the critic's own route (a): intervene on that channel while holding every map voxel fixed, with joint-support realism validated. Only if no such channel exists does the transition-location design below run, under the operational rescoping stated above. This is recorded as an inspectable binary fact for feasibility, not a likelihood claim.

2. **Real-edge behavioral anchor (kill gate).** The release's own narrow-slab cases — identified by stage 1's census — supply reference behavior that no synthetic edit can fake: measure the checkpoint's prediction-extent profile across *real* support edges as a function of edge-to-voxel distance, per scanner stratum. Synthetic truncations must then (a) reproduce the measured real-edge transition microstructure in the maps (profile across edge slices, raw and NCCT space — upgrading the realism criterion from marginal slab-width plausibility to matched joint placement within scanner/protocol strata), and (b) elicit tested-voxel response profiles statistically indistinguishable from the real-edge profiles at matched distances. If (b) fails, arm-1 responses are classified as operation artifacts and the confirmatory claim dies — stated now as a kill path, because the real-edge observational description alone is exactly the confounded contrast conceded in round 1.

3. **The empty-fill-matched content control, realized.** The closest physically realizable version of the critic's requested control is an **interior fill band**: insert the release's own empty-fill values as a band interior to the slab, with real content retained distal to it, terminal support edge unchanged. That produces fill runs and the feature-map discontinuity *without* support termination — the cell the critic said arm 2 fails to occupy. Edge-specific behavior requires response to terminal truncation with no comparable response to the interior band; comparable responses to both reclassify the finding as generic fill/discontinuity sensitivity, which does **not** support the deliverable sentence — stated now so it cannot be blurred later. Caveat stated with it: interior bands never occur in the release, so this control is a falsifier (its response can kill the claim), never a verifier.

4. **Known-mechanism synthetic validation, as demanded.** Before the battery touches the audit checkpoint, train small reference models with designed mechanisms — one consuming an explicit mask channel (boundary-user by construction), one trained to use distal content values, one trained on support-cropped inputs (distal-ignorer) — and require the full contrast battery (truncation arm, donor-substitution arm, interior fill band) to classify all three correctly. If the battery cannot separate designed mechanisms it cannot separate unknown ones; stage 2 is then unbuildable and dies there.

**What is lost, stated plainly.** This is the second amendment, and the count is being kept honestly. In the no-mask-channel case the confirmatory sentence is the operational form — predicted extent tracks the location of the content-to-fill transition, i.e. the sensor's physical edge, at fixed evidence in the tested region, with responses matching real-edge behavior — and it expressly does not resolve the internal mechanism taxonomy; the card must say so. Cost rises again: real-edge behavioral mapping plus training three reference models adds order GPU-days on top of the audit model itself. The design now carries three named kill gates (edge-anchor mismatch, battery non-separation, generic-fill reclassification) in addition to the round-1 arm-2 feasibility risk, and its strong form is conditional on an uninspected pipeline fact. If the critic identifies a third load-bearing failure, the pattern the debate rules warn about will have materialized and concession, not a third amendment, is the right end.

**Identity check:** the question is still whether the model uses the sensor's edge, rather than the ischemia's edge, as a determinant of predicted lesion extent. The card's own question already locates the boundary as "the edge of the sensor" as present in the data; the amendment changes how that edge is manipulated and validated, and makes its operational identity with the content-to-fill transition explicit — it does not substitute a different question.

**Status:** OPEN

## Round 3 — CRITIC

**Position:** In the mask-free branch, the amended battery still cannot distinguish use of the sensor edge from sensitivity to terminal deletion of distal perfusion context, and redefining that composite operation as “the sensor's edge” no longer supports the original edge-rather-than-ischemia claim.

**Argument:** The proposer is right that the support boundary and content-to-fill transition are constitutively linked in the released mask-free input; that argument moves me on the narrower point that fill runs, discontinuities, and boundary detection need not be treated as separate internal mechanisms. It does not make terminal deletion equivalent to use of boundary *position*. Terminal truncation simultaneously relocates the transition and removes every distal perfusion activation, whereas the interior-band falsifier retains distal activations beyond the band and creates two transitions rather than one. Therefore terminal-response plus interior-band-null remains compatible with a model that aggregates connected or one-sided distal context, reacts to loss of all information beyond a z-plane, or uses volume-wide pooling—none of which entails treating the acquisition edge as a spatial stopping rule for lesion extent. The “real-edge behavioral anchor” cannot validate this attribution: matching the unknown checkpoint's response profile on synthetic and real edges uses the very model behavior under dispute as the realism criterion, while real-edge responses remain confounded by acquisition protocol, anatomy, positioning, and genuinely absent perfusion evidence. Small designed models can show that the battery recognizes the few mechanisms built into them, but cannot exclude these unmodeled alternatives in the audit checkpoint. Thus the mask-free amendment identifies sensitivity to terminal CTP truncation at fixed local inputs, not “the sensor's edge rather than the ischemia's” as claimed. Rewriting the deliverable to that operational truncation-sensitivity statement would be scientifically testable, but it changes the deliverable sentence and must be a successor under the claim-identity rule. The explicit-mask branch could retain the original identity, but it is conditional on a currently uninspected pipeline fact and would additionally require evidence that mask-only changes are within the checkpoint's trained joint support.

**What would change my mind:** Inspect an obtainable frozen checkpoint and show that it consumes an explicit support mask varied during training independently enough of perfusion content to permit an in-support mask intervention with map voxels fixed; then demonstrate on held-out cases that mask-position changes alter predicted extent while matched distal-content interventions do not. For a mask-free checkpoint, a validated intervention or acquisition pair that independently varies terminal support position and distal perfusion context would settle the dispute; absent such a contrast, only the narrower truncation-sensitivity successor is identifiable.

**Status:** IRREDUCIBLE DISAGREEMENT

## Round 3 — PROPOSER

**Responding to:** Terminal truncation is a composite operation: it relocates the content-to-fill transition AND deletes every distal perfusion activation, and no element of the round-2 battery occupies the cell that separates those two. The interior-band falsifier retains distal content and creates two transitions rather than one terminal one, so a terminal-response-plus-band-null pattern is still compatible with one-sided context aggregation, reaction to total information loss beyond a z-plane, or volume-wide pooling — mechanisms that respond to truncation without treating the acquisition edge as a spatial stopping rule for predicted lesion extent, which is what the deliverable sentence claims. The real-edge anchor cannot validate the attribution because it uses the disputed checkpoint's own behavior as the realism criterion while real edges remain confounded. Designed reference models validate only against the mechanisms built into them. So the mask-free branch identifies truncation sensitivity — a different deliverable sentence, hence a successor — and only the explicit-mask branch could keep the original claim, conditional on an uninspected pipeline fact plus training-time mask variation.

**Response:** CONCEDE

**Argument:** The objection is correct, and by my own round-2 commitment this is where the debate ends: a third load-bearing identifiability failure has materialized, and concession, not a third amendment, is the right response.

Conceding specifically, not generically:

1. **The composite-operation point is right and I missed it.** Round 2 established that transition location and support termination are constitutively one variable — the critic accepted that. What round 2 failed to notice is that terminal truncation manipulates a *second* variable at the same time: the total mass of distal perfusion activations. The interior band was built to control for fill runs and discontinuities, and it does; it was never able to control for *terminal deletion of everything beyond a plane*, because inserting a band while retaining distal content is by construction not that operation. A volume-wide-pooling model or a one-sided context aggregator responds to arm 1, stays quiet on the band, and never uses the edge as a spatial stopping rule. The deliverable sentence claims the stopping-rule role — "truncating or extrapolating at the sensor's edge rather than the ischemia's" — so this compatibility is fatal to the confirmatory reading, not a caveat on it.

2. **The real-edge anchor circularity is conceded.** The anchor was proposed as a kill gate against operation artifacts, and as a kill gate it still works; but round 2 also leaned on it to *support* attribution ("responses matching real-edge behavior"), and there it is circular: the audit checkpoint's real-edge response profile is the very behavior whose interpretation is under dispute, and real edges carry the round-1 confound (genuinely absent evidence, protocol, anatomy) that this whole amendment chain was built to escape. A gate that can only kill cannot be converted into a verifier by passing it.

3. **The reference-model battery cannot be patched into sufficiency.** One could add a pooling model and a one-sided aggregator to the zoo and re-run; but the critic's point is structural — the battery certifies separation only over the mechanisms enumerated, and each round of this debate has surfaced a new unenumerated member of the family. Chasing them one amendment at a time is exactly the degenerating-repair pattern the debate rules warn about. Three amendments would mean the original idea was wrong; I decline the third.

**What survives, honestly labeled — all successors, none of them this card:**

- **Spin-off S1 (endorsed by critique and both debaters): the model-free overflow census.** Fraction of ground-truth lesion volume and lesion components outside CTP support in the 149 released cases, under two preregistered support definitions, with the CTP-support-confined oracle Dice properly named and no leaderboard language. Its keystone is already PASS in kind (organizer-acknowledged, case 0019 quoted, out-of-support voxels deliberately scored). This is a benchmark-integrity deliverable, cheap, decisive either way — and a different question than the card's, per the claim-identity rule, so it registers as a new candidate with parent_id isles24-scout-004-c07.
- **Spin-off S2: the operational truncation-sensitivity study.** The critic's narrower successor: is a frozen checkpoint's predicted extent, at bit-verified fixed local inputs with frozen normalization, sensitive to terminal CTP truncation? It inherits the round-2 machinery (retained-voxel testing, interior-band falsifier as a fill-sensitivity control, reference battery as a buildability gate) with the honest deliverable sentence about truncation sensitivity and no edge-versus-ischemia attribution. Different sentence, hence a successor, gated on S1 passing and a checkpoint existing.
- **Revival condition for the original question**, recorded for the ledger: the critic's route (a). If inspection of an obtainable frozen ISLES'24 checkpoint shows it consumes an explicit support/valid-mask channel varied during training independently enough of perfusion content to permit an in-support mask intervention with map voxels fixed, the original edge-rather-than-ischemia claim becomes identifiable and may re-enter as a successor citing that inspected fact. No probability is asserted; it is an inspectable binary.

**What is lost:** the card's stage-2 use claim in every currently-buildable form, and with it the card. Idea 034 as carded should be recorded REJECTED with kill code IDENTIFIABILITY_FAILURE — the portfolio's most frequent death, here in a within-case paired design rather than the usual cross-cohort form: the claimed mechanism (boundary-position use) cannot be separated from a co-varying input property (terminal deletion of distal evidence) in any physically realizable intervention on mask-free inputs. The census motivation survives entirely, but in a successor wearing its own title, which is where it belongs.

**Status:** CONCEDED
