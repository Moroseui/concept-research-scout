# Revision — Idea 019

## Outcome

The defensible experiment is now one conditional rung-1 question: does CT-CLIP's verified `Pulmonary fibrotic sequela` output use information carried by a frozen subpleural cyst-network topology index beyond scar burden, density, and emphysema directions, after explicit support and latent-intervention validity gates?

That question is coherent, but it does not retain the original physician-level deliverable. The proposed index has not been independently validated as honeycombing. Under the 2026-08-10 claim-identity rule, the revised card therefore recommends superseding idea 019 and registering the index-level study as a new successor with `parent_ids: ["idea-019"]`.

## Material changes

1. **Corrected the model endpoint.** The card now targets CT-CLIP ClassFine output index 11, `Pulmonary fibrotic sequela`, which was directly inspected in the official code at commit `a2a155c601987820433c01db69b64d701d3d229d`. Every reference to a pulmonary-fibrosis output was removed. UIP and prognosis claims were removed because this broad scarring-sequela output does not support them.

2. **Narrowed the question to one X, one output, and one conditional use test.** The confirmatory question is only whether the fibrotic-sequela score uses information carried by the prespecified topology index beyond three frozen nuisance families. The report audit, native/tensor audit, manifold test, sham test, and reconstruction pairs are gates or supporting analyses, not additional scientific questions.

3. **Changed the confirmatory X from honeycombing to a literal computed index.** X is now the deterministic subpleural cyst-network topology index: persistent wall-bounded air-component, adjacency, stacking-depth, pleural-distance, Betti-1, and Euler summaries. The card explicitly prohibits calling this index honeycombing because mimic separability has not been established against paraseptal emphysema, traction bronchiolectasis, and reconstruction-created wall closure.

4. **Resolved the claim-identity boundary as `different`.** The original deliverable says that CT-CLIP uses honeycombing, a named physician-level entity. The revised deliverable says that it uses an unvalidated computed topology index. Independent construct validation is not a qualifier on the same established X; it is the missing fact required to identify X as the thing named originally. Because the named deliverable changed, the card recommends successor registration rather than revision-in-place advancement.

5. **Retargeted the obtainable study from rung 3 to conditional rung 1.** Even a fully positive experiment can establish only use of information carried by the linearly encoded index. Rung 2 still requires acquisition- and population-artifact exclusion. Rung 3 requires an obtainable externally validated honeycombing quantifier with released weights and mimic validation, or independent adjudicated construct validation with frozen-threshold transport to CT-RATE.

6. **Added K1 before any image download.** A frozen report-text/RadBERT audit must find at least 30 honeycomb-mentioning, fibrotic-sequela-positive evaluation volumes, including at least 15 in the required thin-slice stratum. The report language is used only to establish candidate support. It never defines X, validates X, or enters the confirmatory claim. Failure is a decisive `DATA_INSUFFICIENT` result for this route.

7. **Replaced naive projection with a gated minimal-displacement affine erasure.** Naive direction subtraction no longer counts as causal evidence. Validation-only gate G2a requires projected embeddings to meet frozen native-neighborhood and density-equivalence margins. G2b requires the topology effect to exceed case-matched sham projections equated for embedding displacement and local ClassFine-head directional sensitivity.

8. **Made gate failure automatically cancel the confirmatory test.** K1, index preservation/encoding, G2a, and G2b must all pass before the untouched test set is used. If any intervention-validity gate fails, association and reconstruction-pair analyses remain explicitly exploratory and no rung-1 claim is made.

9. **Demoted reconstruction pairs to complementary evidence.** Geometry-matched same-acquisition pairs can show whether score changes follow reconstruction-rendered topology changes while anatomy, site, habitus, referral, and positioning are held fixed. They cannot separate wall topology from generic noise and high-frequency texture introduced by reconstruction, so they are not a substitute causal instrument.

10. **Corrected the prior-failure analysis.** The revision no longer claims that latent erasure inherently avoids idea 006's out-of-distribution failure. It lives only if G2a/G2b validate the intervention; otherwise it dies like idea 006 for rung-1 purposes. It also explicitly inherits the annotation-provenance lesson: report terms cannot confer the name honeycombing, although the primary index-level analysis itself needs no reader labels. Circularity does not apply because X is neither the label nor a report re-encoding.

11. **Strengthened the keystone.** The load-bearing conjunction is adequate thin-slice support, measurable encoding of the frozen index, and a latent intervention that passes both manifold and matched-sham gates. The nearest inspected facts—the exact output name and preprocessing—do not establish any part of that conjunction. `keystone_status` remains `NOT_INSPECTED`, keeping feasibility and novelty confidence capped at 3.

12. **Preserved meaningful negative outcomes without overstating nulls.** K1 failure decisively kills this data route. G2a or G2b failure decisively invalidates this intervention and prevents wasted test-set work. After all gates pass and adequate sensitivity is established, an equivalently null topology effect with a functioning positive control weakens use of the tested linear index. It does not establish absence of nonlinear topology use or absence of honeycombing use.

13. **Named the remaining alternatives.** A positive may still reflect mimic mixture in the index, correlated distributed scar severity, or latent distribution shift missed by local manifold metrics. Scanner/vendor, protocol, reconstruction, site, positioning, habitus, prevalence, referral, and report leakage are addressed explicitly, and the card states which remain unresolved.

14. **Reduced unsupported scores and used the Mode C rubric.** Medical relevance is 3 because the endpoint is broad fibrotic sequela and X lacks clinical validation. Interest is 4 because the physician-level name is unavailable. Identifiability is 3 because the intervention gates address important alternatives but not construct validity or all nonlinear correlation. Negative-result value is 3. The Mode C score is `4.05 = 0.30*5 + 0.25*3 + 0.20*4 + 0.15*3 + 0.10*5`. Feasibility and novelty confidence remain informational and capped at 3.

15. **Removed unnecessary architecture and overreach.** The former 370-volume fixed plan, unnamed external-site replication, prognosis framing, multiple comparator directions beyond the three primary nuisance families, and claim that topology-direction erasure is intrinsically in-distribution were deleted. No code, image edit, model training, or annotation campaign is proposed.

## Claim retention

The revised study preserves the model family and part of the physical motivation, but it changes the thing asserted in the deliverable from named honeycombing to a bespoke index explicitly not validated as honeycombing. This crosses the ledger's claim-identity boundary and should trigger supersession and successor registration.
