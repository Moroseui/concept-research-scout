# Summary

First separate fusion’s better placement from its changed predicted volume; second diagnose small-lesion misses and whether admission-based size routing is useful. All evidence concerns exposed development patients; executed Sprint13A r4 source and prediction assets were not inspected. ## Two proposed first tests

**Test1: Does fusion improve placement at the same predicted amount?** On the saved split101/seed1 products, compare tree, nnU-Net and their fixed equal-weight average. Use each patient’s saved tree predicted voxel count for all three. Fix common smoothing from documented existing settings, a verified common 2-mm grid/domain, deterministic ties and zero extension outside each model’s legitimate support. Keep full scoring truth. Report a common-support sensitivity separately, without removing outside-support truth. If the requested voxel count exceeds a sensitivity’s candidate domain, report infeasibility rather than silently changing the amount.

Primary: mean paired patient Dice, fixed fusion minus tree. Secondary: nnU-Net minus tree, lesion F1, matched-lesion recall, false-positive components, original own-volume rows and equal-volume identity. Both predicted volume and volume error should match by construction in the equal-amount comparison; equality is not validation of volume estimation. A useful placement lead requires a positive Dice signal without a clear detection penalty; “no significant harm” is not proof of noninferiority. Any numerical advancement margin must be fixed before computation, not chosen from results. This remains a diagnostic proposal, not an automatic winner rule.

**Test2: What produces the small-lesion deficit, and can predicted size route existing masks usefully?** First report parent, fixed fusion and union results across all existing positive patient-volume bins and empty truth separately, with whole-cohort estimates. Retain the distinction between patient total volume and component volume. Reconcile the saved official lesion-matching definition, connectivity, one-to-one matching, IoU≥.2 and empty conventions before attributing a loss to merges/splits. Report unmatched truth/prediction components, mergers/splits, patient-averaged matched-lesion recall and false-positive components against both parents; preserve Dice, lesion F1 and volume error. Compare existing threshold-before-resampling and resample-before-threshold masks as a geometry sensitivity. No pruning, threshold sweep or any-overlap substitution.

For the operator’s gate hypothesis, add a **single fixed exploratory router**: if saved tree predicted volume is <5 ml, use the reported tree/nnU-Net union; otherwise use the reported tree mask. Tree volume zero enters the first branch. No true-volume input is used for routing, and missing/nonfinite scores stop that comparison. This explicitly tests a recall-seeking small-predicted-volume intervention, not a three-specialist model. Keep tree, nnU-Net, unconditional union and fixed fusion as comparators; report paired whole-cohort differences and all actual-size strata without selecting the best comparator after seeing outcomes. A predicted-volume versus true-volume group table, including empty truth, describes routing error only. It must not be used to optimize cutoffs or choose branch models on the scored patients. The operator’s original three-size ambition remains untested by this deliberately smaller first test.
