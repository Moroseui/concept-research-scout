# External exploratory notebook evidence

The external adapter admits the two exact operator-identified saved notebook versions, preserving their external origin. It does not execute notebook cells, reconstruct an exit status, claim preregistration or treat the internal 30-case evaluation as an untouched external test.

Private originals are collected before the workflow. `notebook_evidence.preserve_external` preserves every saved output and verifies a narrow, source-reviewed aggregate-stream projection plus code against the exact notebook hash. Unselected outputs and case-level CSV rows never enter model prompts. `drive_science_intake.external_artifact` checks supplied file identities, CSV shape and bounded archive safety/CRC without extracting; `external_collected` verifies future registered Drive originals against their actual request, alias, implementation and byte hashes. Neither helper changes grants or downloads data.

`external_evidence.prepare` writes one private intake outside Git; repeated identical delivery returns the unchanged receipt. A conflicting, altered or partial intake stops. Missing Drive originals remain explicit evidence limitations.

In a private scientific checkout containing the current policy/profile/context, call `external_evidence.interpret(sc, intake_directory)`. This uses `campaign_pipeline.system_stage` for an Astra interpretation and judgment followed by an independent Fable review binding both original outputs. `scientific_authority.seal` attributes acceptance or deferral to the deciding model and the delegated policy. Acceptance permits qualified context use; it grants no scientific launch, dataset expansion, publication, spending or unattended activation.

Register the returned interpretation with `register_interpretation`, then run `consider(sc, entry_id, charter)` independently for `isles24` and `isles24-prediction`. Each consideration cites findings, limitations, contradictions, affected questions and a concrete next action (or reasoned inapplicability/deferral). Register its result with `research_context.register_consideration`. The existing context reader supplies only that charter's consideration. Deliberate blinding returns no evidence or model calls; no historical scores are changed.

A maximum of two author/reviewer rounds is allowed per decision. A completed original stage may be recovered from its preserved provenance and artifacts; an uncertain or incomplete invocation stops without automatic retry. Model deferral preserves the idea, original evidence and reconsideration conditions. A `HUMAN_STOP` marker at the private checkout or applicable evidence directory prevents further stages. Existing system-stage model/resource controls remain active.

The same context registration/consideration path can consume a completed 047b receipt binding its original interpretation, opposing review and next decision. It must not repeat the completed scientific experiment or rewrite historical authorship.

All model stages require reviewed integrated source before real use. Offline tests use explicit synthetic notebooks and fake receipted stages; they are not proof of a real model call.
